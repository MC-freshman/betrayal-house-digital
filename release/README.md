# 山中小屋 v3.7

发布日期：2026-10-09。桌面版 Windows 便携包；本次不发布微信小程序。

## 下载和运行

[GitHub Releases](https://github.com/MC-freshman/betrayal-house-digital/releases/tag/v3.7) 提供 EXE、便携 ZIP 和 SHA256SUMS.txt。
解压 ZIP 后双击 `山中小屋.exe` 或 `启动游戏.bat`。EXE 包含 Python 与 tkinter，无需另装运行环境。

- 本地：单人或同屏热座，可加入机器人，总人数 4–6 人。
- 联机：先运行主机，客户端填写主机 IP 和端口；使用 NATFRP 时填隧道地址与远程端口。
- 可存档和读档；玩家存档放在运行目录 `saves/`，发布包不包含本机玩家存档。
- 保留 1–70 剧本、内置规则、卡牌、房间图鉴与骰子结果展示。

## 相对 v3.6 的更新

- 将原约 2.4 万行剧本实现拆为 `haunts/base.py`、70 个剧本模块和注册入口，`haunt_modes.py` 保留兼容门面。
- 打包显式收集 `game.haunts` 动态模块，防止源码正常而 EXE 缺少剧本。
- 界面按日志、棋盘、详情分别检测变化，日志更新无需重绘整个棋盘。
- 缓存机器人剧本画像；4 号剧本改用动态救援目标和探索条件，避免固定聚集入口及无谓攻击蜘蛛。
- 存档读取增加版本守卫和迁移入口，对高于程序支持版本的存档给出明确提示。
- 提供公开日志与当前行动者访问入口，统一“理智检定”“古代盔甲”等术语。
- 黄金回放支持 `GOLDEN_BASELINE_FILE`，扫描结果使用系统临时目录。

## 验证与已知限制

本次环境为 Windows、Python 3.9.13、PyInstaller 6.22.2。

- `verify_v1.py`：通过，覆盖桌面交互、机器人开局、存读档及剧本提示。
- `check_core_drift.py`：在本地完整项目布局下通过；该检查依赖仓库之外的小程序后端，独立克隆无法执行。
- `replay_golden.py`：186 条历史基准在当前环境均不匹配，此现象此前已有记录。本次保留现有基准，没有用重录掩盖差异。
- 本地改动前参考基线：仅剧本 2 / 68 的 5 条术语变化，其余 181 条一致。
- `verify_haunt_systems.py`：仍在剧本 17 的杀虫剂断言失败，尚未修复；不能声明 177 项专项全通过。
- 4 号机器人目标改进后仍未解决英雄胜率；其余长目标链策略和通用撤退战术仍待后续工作。
- 部分剧本边界机制保留已有电子版简化；本版不增加新的规则完成度承诺。

完整打包核验和发布附件哈希见随发布保存的 SHA256SUMS.txt。
