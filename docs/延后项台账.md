# 延后项台账

记录「已知有缺口、但当前不做」的事项，写明**为什么延后**、**缺什么才能做**、**做完会有什么连带影响**。
目的：避免下一次复查时把延后项误判成漏项，也避免在素材不足时靠猜实现。

更新日期：2026-11-24
