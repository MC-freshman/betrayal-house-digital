# #70 一声非人尖啸

原名：With an Inhuman Cry

## 英雄手册

# 一声非人尖啸

你的同伴痛苦地大喊一声，伴随着非人的叫声，一只怪物消失在阴影中。然后你的同伴开始大笑，他的皮肤和头发开始发生变化，他的眼睛似乎捕捉到了超凡脱俗的光芒。现在他内心有邪恶的东西。

## 现在

留出一些圣印标记和银子弹、醋、园艺用品、喷枪和杀虫剂标记（均为五边形）。还留出几个 力量检定、知识检定 和 精神检定 令牌（三角形）。

## 你对坏人的了解

叛徒已被吸血鬼、狼人或祸害蜘蛛咬伤，并正在迅速转变为类似的怪物。吸血鬼会寻找鲜血与死亡之地；狼人会寻找月亮；祸根 蜘蛛 会尝试传播 蛛网。当……你在 叛徒 完成转变之前用对怪物本性不利的武器击败他时，你就赢了。

## 如何杀死吸血鬼

如果叛徒被吸血鬼咬了，你需要用浸过圣水的武器打败他。在 小教堂、酒窖 或 地下湖 中持有 圣徽、天使羽毛 或德鲁伊符咒的 英雄 可以尝试使用 精神检定 来制造圣水。如果您掷出的骰子数量大于或等于游戏中的玩家数量，请在该房间中放置一个圣印标记。带有 长矛、斧头 或 血匕首 的 英雄 在有圣水的房间中可以将武器浸入水中而不进行攻击。当你这样做时，在该武器上放置一个圣印标记。该武器现在可以用来攻击 叛徒。

## 如何杀死狼人

如果 叛徒 被狼人咬伤，持有银弹令牌的 英雄 必须使用 左轮手枪 击败 叛徒。 熔炉房、研究实验室 或 手术室 中的 英雄 可以尝试 知识检定 创建银弹。如果您掷出的骰子数量大于或等于游戏中玩家的数量，您就成功了，并将银弹标记放置在您的角色卡上。该代币可能像物品一样被丢弃、交易或被盗。您只能创建一颗银弹。如果左轮手枪尚未绘制，您可以通过在保险库中寻找线索来发现它的位置。 保险库被打开后，保险库中的英雄可能会声明他正在寻找左轮手枪位置的线索。如果您这样做，请通知 叛徒 他应该搜索物品牌组，将 左轮手枪 放置在房屋中任何发现的房间中，然后洗牌物品牌组。

## 如何杀死祸害 蜘蛛

如果 叛徒 被虫子 蜘蛛 咬伤，你必须给他喷杀虫剂。 英雄 可以通过轮流搜索其中一个房间而不是进行攻击来获得 厨房 或 储藏室 中的醋、花园或 庭院 中的园艺用品以及 阁楼 或 杂物间 中的喷枪。这些物品可能会像物品一样被丢弃、交易和被盗。含有上述所有三种成分的 英雄 可能会尝试使用 知识检定 来组装杀虫剂。如果您掷出的骰子数量大于或等于游戏中的玩家数量，请丢弃原料并将昆虫喷雾标记放置在您的角色卡上。杀虫剂可以像物品一样被丢弃、交易或被盗。与 叛徒 位于同一房间的带有 Bug Spray 的 英雄 可以使用它来攻击 叛徒。此攻击不需要掷骰子；如果 叛徒 被克星 蜘蛛 咬伤，您将自动获胜。

## 特殊攻击规则

除非使用对其本性不利的特殊武器，否则无法对 叛徒 造成伤害。当你用圣武器、银弹或杀虫剂击败叛徒时，他必须告诉你他是否是匹配的怪物。 叛徒 忽略所有其他来源的损坏。如果你赢了……那个曾经是你朋友的东西倒在地板上，痛苦地嚎叫。你可以看到一些东西在对抗感染，人类试图重新站起来，但它太弱了。随着最后一声喘息，半人怪物四肢摊开在地板上，一点点邪恶离开了世界。

## 叛徒手册

# 一声非人尖啸

獠牙 咬伤 深入你的肉里，你痛苦地弯下腰。随着一声非人的叫声，该生物消失在阴影中，但你已经可以感觉到自己在发生变化。新的力量进入你的四肢。一股黑暗的力量在你的血管中流淌。你微笑。这……这值得为之而活。

## 现在

您的角色仍在游戏中，但已变成 叛徒。预留几个 力量检定、知识检定 和 精神检定 令牌（三角形）。变身时，你不能携带或使用物品。立即丢弃你携带的所有物品和预兆（包括通常无法丢弃的物品，如 血匕首 和 女孩），但不要因为丢失它们而改变你的任何特质。您保留 咬伤 卡。如果您的任何身体特征低于其起始值，请将其提高至起始值。然后，如果您的力量或速度得分是游戏中任何 探险者 中最低的，请将这些特征提高到任何 英雄们 中的最低值。

## 你对英雄的了解

他们试图阻止你转变。当你完成转变，或者所有 英雄们 都死了时，你就赢了。你的变身 你正在变身为吸血鬼、狼人或祸根 蜘蛛。选择一个并偷偷地写下来。您的目标取决于您的选择。如果您要成为吸血鬼，您必须访问 地窖、墓地 和 血房间，从鲜血和死亡中汲取力量。当您进入每个房间时，请秘密记下这一事实（您无需在这些房间中结束回合）。参观完所有三个房间后，您必须对任何 英雄们 和 力量攻击 造成至少 1 点物理伤害才能吸取他们的一些血液。当你完成此操作时，你的转变就完成了，你就赢得了游戏。如果您要成为狼人，您必须参观 阳台、塔楼、庭院、花园和 墓地，让自己暴露在月球上。当您进入每个房间时，请秘密记下这一事实（您无需在这些房间中结束回合）。当您访问完所有五个房间后，您的转变就完成了，您就赢得了游戏。如果你正在成为祸根 蜘蛛，你必须参观所有角落里还没有 蜘蛛 蛛网 的内部房间；它们是 烧焦的房间、温室、吱呀走廊、雕像走廊 和 神秘电梯。当您进入每个房间时，请秘密记下这一事实（您无需在这些房间中结束回合）。当您访问完所有五个房间后，您的转变就完成了，您就赢得了游戏。特殊物品规则 您不得拾取、携带或窃取 作祟 中的物品或预兆。如果您在发现新房间时抽取了新物品或 预兆，则必须立即将其放入该房间，以免它以任何方式影响您（您不能选择丢弃它）。

## 特殊攻击规则

通常，即使你被击败，你也不会因战斗而受到伤害。如果你要成为吸血鬼，请小心沾有圣水的武器；如果是狼人，请避免银弹；如果 蜘蛛 是祸根，请注意杀虫剂。每个怪物都有一种特殊的能力，可以使用它来代替攻击，但使用它会揭示你的本性。如果你要变成吸血鬼，你可以在同一个房间的英雄上放置精神检定令牌来催眠他们；如果是狼人，则需要 知识检定 令牌来感染他们；如果是祸根 蜘蛛，则使用 力量检定 令牌将他们困在网中。在 英雄 的下一个回合中，他们必须进行与您放置的标记相对应的特征掷骰。如果他们掷出 4+，他们就会挣脱并丢弃令牌；否则，他们的回合立即结束并保留令牌。当您离开房间时，带有任何这些标记的 英雄们 不会减慢您的移动速度。如果你赢了……最后的时刻似乎会永远持续下去，因为你感觉到你最后的微弱人性正在慢慢消失，取而代之的是你新的、更强大的本性。然后，最后，它完成了，你也完整了。你认为你在出去的时候杀了他们中的一些人，但这并不重要。你现在自由了，没有什么可以阻止你。
